# Happy 21st Birthday Lovely Manu 💜✨

An immersive, single-viewport 100vh interactive birthday celebration created for **Lovely Manu** by **Pranav Karpe**.

## 🌟 Features
- **Cinematic Landing Page**: Radiant typography, floating 3D WebGL hearts, background music, and cute milestone badges.
- **Background Song**: The iconic Bollywood track *"Raabta"* (*Agent Vinod*) starting directly from the singing vocals and playing continuously across all pages.
- **Sacred 21st Birthday Candle Ceremony**: Blow out the candle flame, trigger heavy celebratory confetti bursts, and receive Swami's divine blessing card.
- **5-Second Heartfelt Transitions**: Smooth emerald-green 0% ➔ 100% progress line interludes giving Manu time to read each blessing.
- **21 Heartfelt Pop-Up Wishes**: Luxury 3D pop-up cards with holographic shimmer, tactile feedback, and milestone unlocking on Wish 21.
- **Sacred Heart Blossom Tree**: Procedural Canvas 2D engine that blossoms into an unmistakable glowing heart of pink & lavender petals.
- **Pranav's Royal Birthday Letter**: An overwhelming letter expressing gratitude, celebrating her natural beauty and innocence, with an interactive love shower.

## 🚀 How to Run
Simply open `index.html` in any modern web browser or start a local server:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).
